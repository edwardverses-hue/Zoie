# our gallery

Birthday site: endless photo gallery (drag in any direction) with a keychain in the middle.

## Add your photos
1. Put photos in `photos/` (WebP or JPG, about 1600px on the long side).
2. List them in `photos.js`.

## Add your charms
Put transparent PNGs in `charms/` and add `src: "charms/name.png"` to each entry at the top of `keychain.js`.

## Run locally
Open the folder in VS Code and use Live Server, or run `python3 -m http.server` and open http://localhost:8000.

Layout comes from Figma file "Zoie", frame "3". Background texture from frame "Desktop - 1".
